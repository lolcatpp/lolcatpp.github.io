# lolcatpp.github.io

Source for the project page at <https://lolcatpp.github.io/>.

Built with [Hugo](https://gohugo.io/) and [PaperMod](https://github.com/adityatelange/hugo-PaperMod).

## Local preview

```bash
git clone --recurse-submodules https://github.com/lolcatpp/lolcatpp.github.io
cd lolcatpp.github.io
hugo server
```

Then open <http://localhost:1313/>.

## Deploy

Pushes to `master` build via [GitHub Actions](.github/workflows/deploy.yml)
and publish to GitHub Pages automatically.
